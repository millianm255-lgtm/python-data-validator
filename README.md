# Python Data Validator

A simple Python tool for validating structured CSV datasets and generating validation summaries.

## Features

- Reads CSV files
- Validates required fields
- Detects missing records
- Generates summary statistics

## Technologies

- Python
- CSV
- Pandas

## Usage

```bash
python validator.py
```

## Example Output

```python
{
    "valid_rows": 2,
    "invalid_rows": 2
}
```
